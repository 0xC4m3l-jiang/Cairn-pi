## 1 需求与验收

**要解决什么**：确保「从 GitHub 拉下来 → 装进 pi → 立刻能用」，而不是只有源码目录里能跑。

**验收判据**：
- README 的安装命令真实可执行（不是指向未发布包）
- 全新克隆 → `pi install` → `/cairn` 命令可用
- 已安装包（不带 `-e`）能跑完整流程：claim → submit → verify → integrate
- 装后 `npm test` 通过、`board.json` 生成
- `npm pack` 产物包含运行所需全部文件

**不做什么**：不发布到 npm（需账号与版本策略，另议）。

## 2 设计逻辑

| --- | --- | --- |
| README 首条安装命令指向未发布包 | `npm view cairn-pi` → 404 | 改为 `pi install git:github.com/0xC4m3l-jiang/Cairn-pi` |
